## Cómo subirlas

1. Abrí esta carpeta en GitHub y seleccioná **Add file → Upload files**.
2. Arrastrá las fotos o capturas y confirmá con **Commit changes**.
3. En el README principal reemplazá cada comentario `<!-- FOTO ... -->` por una imagen Markdown, por ejemplo:

```md
![Horno industrial](docs/img/01-horno-completo.png)
```

Las imágenes **no se muestran automáticamente** por subirlas. Es necesario incorporar el enlace Markdown en la sección correspondiente. No uses este directorio para material con información confidencial, credenciales o datos sensibles de instalaciones industriales.

Se conserva también `docs/capturas/`, que contiene capturas técnicas de prueba del software y no es lo mismo que esta galería de fotografías de presentación.
